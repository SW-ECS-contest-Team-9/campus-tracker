# 서경대학교 러프 3D — QGIS 3.44

`campus_3d.qgz`를 QGIS에서 엽니다. 저장된 **Campus 3D** 뷰가 함께 열리도록 구성했습니다. 닫힌 경우 `보기 → 3D 맵 뷰 → Campus 3D`를 선택하세요. 자료를 옮길 때는 이 폴더 전체를 함께 옮기세요. 추가 플러그인이나 인터넷 연결은 필요 없습니다.

## 구성

- `campus_3d.qgz`: 색상·DEM 지형·건물 3D 심볼·카메라를 저장한 프로젝트
- `campus.gpkg`: 모델 12개, 원본 건물 12개, 캠퍼스 경계, 등고선
- `terrain_dem_2m.tif`: 등고선과 표고점을 보간한 2m 격자 DEM
- `building_heights.csv`: 사용 높이, 근거, 기초/지붕 표고, 주의사항
- `validation.json`: 지형 자료 일치도와 데이터 검사 결과
- `preview_qgis.png`: QGIS 3D 렌더러로 내보낸 미리보기(생성 성공 시)
- `source/`: 재현에 필요한 입력 자료와 PostGIS 메타데이터 스냅샷
- `build_campus.py`: QGIS Python용 재생성 스크립트

## 지형과 모델의 한계

- 등고선 39개 피처와 표고점 78개를 사용했습니다. 등고선 꼭짓점을 3m 이하 간격으로 세분하고 삼각망 선형 보간으로 DEM을 만들었습니다.
- 지형은 캠퍼스 경계 주변 90m까지 포함하며 건물은 사용자가 제공한 캠퍼스 도형만 모델링했습니다.
- EPSG:5174 지형을 명시적 7매개변수 지리기준 변환을 거쳐 EPSG:5186으로 변환했습니다. 건물과 결과물은 EPSG:5186, 단위 m입니다.
- 높이는 원자료의 표고값을 사용합니다. 타원체고로 변환하거나 지오이드 높이를 더하지 않았습니다. 수직 과장은 1배입니다.
- 등고선만 보간한 표면과 표고점의 차이 중앙값 0.31m, 절대차이 90백분위 3.41m. 최종 DEM에는 표고점도 포함했습니다. 이 수치는 독립 현장 검증이나 보장 정확도가 아닙니다.
- 2m는 출력 격자 간격입니다. 2m 실측 정확도나 계단·옹벽·절토면·건물 주변 평탄지를 정확히 재현한다는 뜻이 아닙니다. 선형 삼각망의 평탄 삼각형과 꺾임이 일부 보일 수 있습니다.
- 각 건물은 수평 지붕의 단순 덩어리입니다. 기초는 외곽 DEM 최저값보다 1m 아래, 지붕은 외곽과 내부 대표점의 표고 중앙값에 높이를 더했습니다. 수인관은 임시 높이대로 만들면 일부가 지형에 묻혀, DEM 최고점 위 3m까지 지붕을 상향했습니다. 경사지와 교차해 기초가 떠 보이지 않게 했지만 출입층·지하층·실제 지붕 절대표고는 검증되지 않았습니다.
- 북악관 DB에는 출입층 표고 135.65m가 있지만 그 출입층의 지상층 번호가 불명확하므로 건물 전체 지붕 표고 기준으로 적용하지 않았습니다.
- 주변의 연두색은 지형 배경색, 캠퍼스의 아이보리는 경계 채움색입니다. 실제 녹지·도로·포장 구역 분류 자료를 의미하지 않습니다. 창문·지붕 장식·재질·수목은 만들지 않았습니다.

## 수정

건물 속성표의 `roof_m`(지붕 절대표고), `base_m`(기초 절대표고)을 수정하면 3D 높이가 변경됩니다. 돌출 높이 식은 `roof_m - base_m`입니다. `height_m`은 참고 높이이므로 단독 수정만으로 모델은 변하지 않습니다. 해당 건물 높이를 Δ만큼 변경할 때 `height_m`, `roof_m`에 각각 Δ를 반영하고 `height_source`, `note`를 갱신하세요. `extrusion_m`은 생성 시점의 참고값입니다.

레이어 목록에서 **등고선 · 원자료**를 켜면 2D 지도에서 원본 등고선을 확인할 수 있습니다. 3D 뷰의 지형은 이 선의 표시 여부와 무관하게 DEM에 반영됩니다.
