## 1. 목표

기압계 상대고도(`relativeAltitude`)는 변화량은 정확하다. 하지만 영점이 세션마다 다르고, 날씨 기압 변화로 서서히 표류한다. 지금 fusion-v4는 절대 높이 기준을 `median(GPS 타원체고 − 기압 Z)`로 잡는다. 그런데 아래 진단처럼 iPhone 절대고도는 이 캠퍼스에서 세션마다 수십 m씩 틀린다.

서울시 1:5000 수치지형도(등고선·표고점)로 지형 DEM을 만들어 **"실외에서 걷는 순간 = 지면 + 폰 높이"**라는 기준을 세운다. 이를 통해 다음을 얻는다.

1. 기압 상대고도를 절대고도(해발/타원체고)로 바꾸는 **Z 영점**
2. 장시간 세션의 **기압 표류 보정**
3. 실외 높이 검증, 그리고 이후 지면 대비 높이와 층 추정의 기반

- **측지계 변환:** PostGIS `ST_Transform(…5174→5186)`은 PROJ DB의 Korean 1985 → WGS84 변환을 사용한다. 7-파라미터(`-115.80,474.99,674.11,1.16,-2.31,-1.63,6.43`)를 명시한 결과와 5 cm 이내로 일치한다. **datum 변환이 빠지면 308 m가 어긋나므로** 반드시 검증 단계를 둔다.
- **건물 지도와 정합:** 수치지형도 등고선은 건물에서 끊긴다. 등고선 길이 중 캠퍼스 건물 도형 안에 들어가는 비율은 변환 그대로일 때 3.6%로 가장 낮다. ±10 m 이동하면 5.3~14.6%, 측지계 미변환이면 11.8%로 오른다. 즉 ±10 m 이내로 정합한다.
- **예외 건물:** 유담관(100~125 m 등고선 6개)과 수인관(130~145 m)은 도형 안으로 등고선이 지나간다. 2015년 이후 신축했거나 경사면을 깎아 지은 건물로 보인다. 해당 영역의 DEM은 시공 전 지형일 수 있다.
- **시험 DEM**(2 m, 인접 등고선 사이 거리 보간): 표고점 대비 잔차 중앙값 −0.64 m, |잔차| 90%값 4.85 m. 5 m 간격 등고선으로 기대할 수 있는 수준이다.
- **iPhone 절대고도:** `altitude − DEM`이 세션별 중앙값 기준 813468d0 −31 m, 89013bdb +16 m, c186b516 −1.5 m, a1dbb118 +5 m다. 수직정확도 ≤ 5 m로 보고된 픽스 161개의 중앙값은 −30.9 m다. **GPS 고도로는 Z 영점을 잡을 수 없다.**

## 3. 높이 기준 체계

| 값 | 정의 |
|---|---|
| `H_terrain(x,y)` | DEM 정표고(인천 MSL, 2015년 지형) |
| `N` | 지오이드고. 지형 버전마다 상수 하나(초기값 22.54 m, 출처 기록) |
| `h_phone` | 걷는 동안 폰의 지면 위 높이. 설정값(손 1.1 m, 주머니 0.9 m. 기본 1.0 m, σ 0.3 m) |
| `z_rel(t)` | 기압 상대고도(센서 재시작에도 연속) |
| `b(t)` | 영점·표류: 절대 정표고 = `z_rel(t) + b(t)` |
| 출력 | `orthometricHeight = z_rel + b`, `ellipsoidalAltitude = z_rel + b + N`(Cesium 표시용), `heightAboveGround = z_rel + b − H_terrain(x,y)` |

## 4. 가공 파이프라인 (P1)

새 명령: `npm run terrain:import -- --source=<폴더> --buffer=300 --resolution=2`. 기존 `spatial-import.ts`와 같은 구조(Node, 의존성 추가 없음)로 만든다.

1. **원본 확인:** `.shp/.shx/.dbf/.prj` 존재 여부와 `.prj`가 Korean 1985 Modified Central Belt인지 확인한다. 다르면 중단한다. 원본 파일별 SHA-256을 기록한다.
2. **파싱:** `spatial-import.ts`의 SHP/DBF 파서를 PolyLine(type 3)·Point(type 1)까지 확장한다. DBF 인코딩은 CP949다.
3. **범위 자르기:** 활성 캠퍼스 지도 범위에 버퍼를 더해 5174 좌표로 변환한 사각형으로 자른다. 레코드 bbox로 먼저 거른 뒤 꼭짓점 단위로 자르고, 잘린 조각은 **별도 선으로 분리**한다. 프로토타입에서 같은 등고선의 조각을 이어 붙였다가 가짜 선분이 생겨 잔차가 12 m까지 커졌다.
4. **좌표 변환:** PostGIS `ST_Transform(geom, 5174 → 5186)`을 쓴다. 변환 직후 **기준점 검증**: 캠퍼스 중심의 변환 결과가 7-파라미터 결과와 0.1 m 이내인지 확인하고, 아니면 중단한다(측지계 누락 시 308 m 오류 방지).
5. **DEM 생성**(EPSG:5186, 기본 2 m 격자, 캠퍼스 + 300 m 범위 ≈ 850×850)
   - 등고선 높이별로 거리 변환(EDT)을 하고, 가장 가까운 등고선과 반대편 인접 등고선 사이를 거리 비율로 선형 보간한다. 2차원 EDT를 TS로 구현한다(Felzenszwalb, 선형 시간).
   - 표고점 잔차를 60 m 이내에서 거리 가중으로 보정한다(봉우리·안부 보완).
   - 셀별 σ: 등고선·표고점 위 0.5 m, 등고선 사이 최대 2.5 m. 경사 항(정합 오차 2 m × tan 경사)을 더한다.
   - **변경 의심 영역 마스크:** 등고선이 지나가는 건물(유담관·수인관) + 5 m 버퍼, 경사 > 45°인 셀. 이곳은 σ를 키우고 영점 앵커로 쓰지 않는다.
6. **품질 게이트**(실패 시 활성화 거부, 보고서 출력)
   - 표고점 잔차: 중앙값 |r| ≤ 1 m, 90%값 ≤ 5 m(시험값 −0.64 / 4.85 m)
   - 건물 정합: 등고선 길이 중 건물 내부 비율이 0 이동일 때 최소인지 확인(±10 m 이동과 비교)
   - 등고선 교차·높이 역전 없음
   - 등고선이 지나가는 건물 목록 출력
7. **저장:** 새 테이블 `terrain_versions`를 만든다. 지형은 캠퍼스 지도와 출처·갱신 주기가 다르므로 별도로 관리한다.
   ```sql
   CREATE TABLE terrain_versions (
     id text PRIMARY KEY,                    -- 예: seoul5000-2015-c1
     source_sha256 text NOT NULL, srid int NOT NULL CHECK (srid = 5186),
     vertical_datum text NOT NULL,           -- KVD_INCHEON_MSL
     geoid_separation_m double precision NOT NULL, geoid_source text NOT NULL,
     origin_x double precision NOT NULL, origin_y double precision NOT NULL,
     resolution_m real NOT NULL, width int NOT NULL, height int NOT NULL,
     heights bytea NOT NULL,                 -- Float32 LE, 남서쪽부터 행 우선, NaN = 범위 밖
     sigma bytea NOT NULL,                   -- Float32, 셀별 1σ (m)
     modified_mask bytea NOT NULL,           -- 셀당 1바이트
     active boolean NOT NULL DEFAULT false, imported_at timestamptz NOT NULL DEFAULT now(),
     metadata jsonb NOT NULL DEFAULT '{}'    -- 원본 해시, QA 결과, 자른 범위, 등고선 횡단 건물
   );
   ALTER TABLE collection_sessions ADD COLUMN terrain_version_id text REFERENCES terrain_versions(id);
   ```
   용량은 약 6.5 MB(높이·σ 각 2.9 MB, 마스크 0.7 MB)다. 세션에는 지형 버전을 고정해 재처리 결과를 재현할 수 있게 한다(캠퍼스 지도 버전과 같은 방식).
8. **원본 관리:** 원본(서울 전역 180 MB)은 git에 넣지 않고 경로를 인자로 받는다. 재현성은 원본 해시로 보장한다. 잘라낸 파생물을 저장소에 둘지는 SUPIS 이용 조건을 확인한 뒤 결정한다.

## 6. 퓨전 활용 (P3: fusion-v4 revision 2)

### 6.1 지면 접촉으로 Z 영점 잡기

걷는 걸음 중 아래 조건을 모두 만족하는 걸음을 **지면 접촉**으로 본다.

- 계단 모드가 아니다.
- 추정 위치가 모든 건물 도형에서 `max(3 m, 2σ_xy)` 이상 떨어져 있다.
- 지형 범위 안이고 변경 의심 영역이 아니다.
- `σ_xy · tan(경사) + σ_DEM ≤ 1.5 m`. 급경사에서는 수평 오차가 곧 높이 오차가 되기 때문이다.
- (강화 조건) 최근 10 m 이상 걸은 구간에서 `|Δz_rel − ΔH_terrain| ≤ 1.5 m`. 기압 변화와 지형 변화가 함께 움직여야 한다.

접촉마다 `o_i = H_terrain(x_i, y_i) + h_phone − z_rel(t_i)`를 계산한다.

- 영점 `b`는 `o_i`의 가중 중앙값이다. 가중치는 `1/σ²`이고 σ²는 DEM σ², 위치 σ와 경사의 곱, `h_phone` σ²를 합한 값이다.
- 확정 조건: 접촉 10개 이상, 20초 이상에 걸쳐 있음, MAD ≤ 1.5 m. 여러 값으로 갈라지면(예: 실내를 실외로 오판한 경우) 확정하지 않는다.

### 6.2 기압 표류 보정

- `b(t)`를 랜덤워크 상태로 둔다(기본 2 m/h, 날씨 기압 변화 0.5~1 hPa/h ≈ 4~8 m/h 범위에서 조정).
- 지면 접촉을 관측값으로 쓰는 1차원 칼만 필터를 돌린다. 실시간은 전방 추정, 재처리는 v4의 `finalize`에서 RTS 스무딩한다. 그러면 걷기 전후의 실내 구간도 앞뒤 접촉으로 보정된다.
- 접촉이 없는 구간은 마지막 값을 유지하고 불확실도를 키운다.

### 6.3 우선순위와 기존 방식

- 우선순위: 지형 접촉 → GPS 고도 → 상대고도만.
- GPS 고도는 실외에서 `|H_gps − (H_terrain + h_phone)| ≤ max(10 m, 2·vacc)`일 때만 약한 관측으로 쓴다. 진단에서 본 −31 m 픽스는 걸러진다.
- 지형이 없는 세션이나 범위 밖에서는 현재 v4 방식을 그대로 쓴다.

### 6.4 출력·지표·검증 경고

- `fused_positions`에 nullable 컬럼을 추가한다: `terrain_height`, `height_above_ground`, `z_datum_source`, `z_datum_sigma`
- `fusion_runs.metrics.terrain`: 접촉 수, 영점 σ, 표류 추정량, 실외 잔차 `(z − H_terrain − h_phone)`의 중앙값과 90%값
- 새 검증 경고: `OUTDOOR_BELOW_TERRAIN`(실외 걷는 중 지면보다 2 m 이상 낮음), `TERRAIN_DATUM_UNSTABLE`

### 6.5 후속 확장 (P5, 실험)

- **층 추정:** `heightAboveGround`와 건물별 기준 지면(출입구 높이), 층고 메타데이터로 층을 계산한다. 경사지 건물은 출입구가 여러 층에 있으므로 건물별 메타데이터 입력이 먼저다.
- **지형을 수평 제약으로 사용:** 실외에서 `z_abs ≈ H_terrain(x,y) + h_phone`을 EKF/스무더의 관측(야코비안 = ∇H)으로 넣는다. 경사 ≥ 5% 구간에서는 사면을 가로지르는 방향의 위치 오차를 줄일 수 있다. 실내외 오판 위험이 커서 플래그 뒤에 두고 현장 검증 후 결정한다.

## 7. 현장 검증 (P4)

앱의 마커 기능을 체크포인트로 쓴다. 기준점은 캠퍼스 안 표고점 3개, 정문, 건물 출입구 계단 앞이다.

| 경로 | 확인 내용 |
|---|---|
| 서쪽 급경사 아래 도로 → 계단 → 고원 (높이 차 ≥ 20 m) | 기압 변화량 대비 DEM 변화량, 접촉 영점 σ |
| 고원 실외 루프 5분 | 실외 잔차 중앙값 ±1 m 이내, 경로가 건물을 지날 때 접촉 제외 |
| 건물 계단 2개 층 → 엘리베이터 | 지면 대비 높이 ≈ 층고의 배수 |
| 실내 정지 1시간 + 실외 걷기 전후 | 표류 추정량과 앞뒤 접촉 일치 |

완료 기준:

- 실외 걷기 구간 Z 잔차 중앙값 |r| ≤ 1 m, 90%값 ≤ 2.5 m
- 영점 σ ≤ 1.5 m
- 기존 Z 경고 세션(89013bdb, 52f472a2, 813468d0)에서 실외 구간 경고 0건

## 10. 결정이 필요한 사항

1. 걷는 동안 폰 높이 기본값(1.0 m)과 주요 휴대 방식
2. SUPIS 원본·파생 DEM을 저장소에 둘지 여부(이용 조건)
3. 지오이드고 공식값(KNGeoid18) 확인 방법. 확인 전까지는 iPhone 값 22.54 m 사용
4. 건물별 출입구 높이·층고 메타데이터 제공 가능 여부(층 추정용)
5. 프리뷰 등고선 오버레이 제공 여부
